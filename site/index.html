Plan your networks, run their DNS and DHCP, from one place.

CIDRella is an IP address management appliance for home labs and small to medium networks. It sits between a spreadsheet and NetBox: subnets, addresses, DNS records and DHCP scopes in one model, served by dnsmasq, or by PowerDNS and Kea.

What it does

Addresses, names and leases that agree with each other

An address has one state, and DNS, DHCP and the scanner all read it. Reserve an address and its DHCP reservation, forward record and PTR follow.

IP address management

Nested subnets, folders, VLANs and named ranges, in a table or a grid with one cell per address.

DNS

Forward and reverse zones with A, AAAA, CNAME, MX, TXT, SRV and PTR records. DNSSEC validation, and upstreams over plain DNS, DNS over TLS or DNS over HTTPS.

DHCP

Scopes, reservations, option defaults and live leases, with bulk changes across scopes and DNS records made from leases.

Filtering

Category blocklists on a refresh schedule and country allow or block lists, applied by CIDRella's own DNS proxy, with a pause per host.

Watching the network

Liveness scans, rogue hosts, rogue DHCP servers and IPv6 routers, device and OS fingerprints from DHCP, and anomaly detection for beaconing and DGA-like names.

Operations

Signed in-app updates with automatic rollback, scheduled backups, an audit trail of who changed what, role-based access, two-factor sign-in and a Pi-hole import.

Getting it running

Install

Native on Debian or Ubuntu with systemd, or in Docker. Linux on x86-64.

Native install

Read the script before you run it. It installs the dependencies, downloads the latest signed release, checks its signature and sets up the services.

curl -sSL https://raw.githubusercontent.com/fatcat/cidrella/main/scripts/install.sh -o install.sh
less install.sh   # review it first
sudo bash install.sh

Docker

Builds the image from source. Good for trying it out; updates come from rebuilding, not from the app.

git clone https://github.com/fatcat/cidrella.git
cd cidrella
docker compose up -d --build
Install only from the GitHub releases. Every release tarball is signed with minisign and checked before it is installed or applied as an update. Each release page also links a VirusTotal scan of its tarball. Full details are in INSTALL-NATIVE.md and INSTALL-DOCKER.md.
